## 入口与复现

在仓库根目录执行，默认CPU、4线程、seed2026、batch4096：

```bash
mkdir -p workspace/kr_time_budget/data/v3/logs
uv run python -u -m workspace.kr_time_budget.pipeline.build_requests_v3 > workspace/kr_time_budget/data/v3/logs/build.log 2>&1
mkdir -p workspace/kr_time_budget/runs/exit_v5
uv run python -u -m workspace.kr_time_budget.pipeline.run_exit_v5 > workspace/kr_time_budget/runs/exit_v5/run.log 2>&1
uv run python -m workspace.kr_time_budget.pipeline.audit_v5
uv run python -m workspace.kr_time_budget.pipeline.report_v5
uv run pytest -q workspace/kr_time_budget/tests tests/rosen/utils/test_optimize.py
```

数据入口支持 `--source`、`--output`；训练入口支持 `--data`、`--output`、`--models`、`--device`、`--batch-size`。全量数据构建已完成时复用manifest；训练完成的模型复用结果，未完成的模型目录会拒绝自动覆盖。不同配置或重新生成数据必须使用新目录，避免旧Schema/指标混用。

单batch模型与原生两阶段链路验证：

```bash
uv run python -u -m workspace.kr_time_budget.pipeline.run_exit_v5 --smoke --output workspace/kr_time_budget/runs/exit_v5_smoke
```

smoke仅用于验证链路，指标标记full_train=false/full_test=false，不能用作正式实验结果。

## v4 两处修改（继承基础）

按 [Argon 5反馈](<../../../../Argon-plans/5反馈 5.md>) 执行。直接复用data/v3，无需重建数据。单威布尔shape=clamp(1.05+softplus,max=5)，scale=softplus×30+0.5；gamma由累计风险增量稳定计算。预算末层从6维改为2维，其他同名共有参数初始化与v3逐值相同。

Budget及Ours预热均预测gamma×sigmoid(2.6)。Ours进入第二阶段时才把未训练的内容末层权重归零、bias设2.6；Content/Fusion头保持v3初始化，所以两个基线全量预测可逐值复现。完整valid的切换预测差和LogLoss差必须为0；阶段2预算全部state和probe gamma必须不变。

新增S/gamma在时间不回退的相邻Request上非增断言。IFR仅约束预算gamma，右塔全特征可使最终乘积随屏上升；不对最终预测强行施加单调。s0约0.930862低于训练正例率0.936478，该预热概率上限按反馈保留并在报告说明。

本轮日志、checkpoint、预测、单调/饱和诊断和审计在runs/exit_v5；25项测试通过。v3/v4报告生成器写history下的历史报告，不覆盖当前报告。v5报告依赖audit_v5生成的机制核对文件。

## 数据和特征口径

54字段定义及Schema在 `workspace/kr_time_budget/pipeline/kr_request_schema.py`；预处理在 `build_requests_v3.py`；当前模型在 `workspace/kr_time_budget/pipeline/time_budget_v5.py`（复用v3基础编码）。使用Sparse、MultiSparse与Float32数值；数值Setting固定[0,1]为恒等变换，log1p明确在上游仅应用于两个用户先验和两个开场前消费计数。物理时钟不归一化后代入生存公式。

- 合并三份完整19列日志，按全部19列去重；保留来源序号/源行号和event_id。排序含稳定平票次序，然后沿用30分钟切场、M=6倒切、每用户首尾场排除。
- 顶部不足6条事件为chunk0，只提供历史。前屏计数和前两chunk标签可包含chunk0；is_first_req按req_idx=1定义。
- Session场景取首条tab，Top5按训练范围可用Session数确定，本次为1/0/2/4/3。先切场倒切再过滤场景，不提前打乱日志。
- train整场结束日期≤20220506；valid整场在20220507；test整场在20220508。跨训练/验证或验证/测试日期边界的场排除，保持Session不交叉；原始events和sessions保留。
- 训练用户历史只用开场日期之前已结束的Session，全体用户过去场均值以m=5平滑；valid/test固定使用截至0506快照。用户历史不因“用户是否训练见过”而被替换为常数。
- 物品CTR/long_view来自完整日志过去日曝光，α=20平滑；验证/测试只查询0506截止快照，不使用全月统计侧表。当前日及未来反馈不用于该日训练特征。
- positive=任一like/comment/follow/forward，单视频0/1，所以上一屏计数≤6。B3不用中间播放时长，只用二值反馈；hist_tags为前两chunk click或long_view的视频标签。
- 标签保留重复，按事件与原标签顺序拼接，MultiSparse sum；slate最多12、hist最多15，head截断。两列分别train-fit词表和表参数。缺失标签/类型用__MISSING__，无历史为空袋。distinct tag计数按原始token、排除缺失，可能超过6。
- 片长来自日志duration_ms，沿用3～600秒裁剪后求均值并转分钟；作者数排除缺失ID。裸视频/作者/音乐ID不建Embedding。
- elapsed_min遵从屏末末条timestamp减场首timestamp加末条clip播放；delta固定1分钟。elapsed不进入预算参数网；v5仅在Ours右塔将elapsed_min/req_idx置零，Fusion继续全字段。预算只激活B1和开场情境/前序当日消费。

## rosen与训练

原生ParquetStreamDataset产生batch，DataLoader使用batch_size=None。模型通过OmniEmbLayer/EmbView调用Schema的compute_tensor，多标签聚合不手写查表。预算Embedding仅创建其实际消费字段，与内容参数独立，初始同名表值相同；没有重复挂载同一ModuleDict。

原生BaseTrainer训练、EvaluatorManager分域与总体评估、EarlyStopper指定LogLoss。实验Trainer只增加25%/50%验证和恢复best；TwoStageRunner负责创建独立第二阶段模型、优化器和Trainer，模型从选中的预热snapshot加载，并冻结整个预算路径。内容bias=+2.6。

基线1epoch，相乘模型1+1epoch；物理/effective batch4096，无累积。AdamW lr=1e-3，split_model_params_by_decay分组，普通矩阵1e-6，Embedding/bias/一维参数零衰减。每阶段比较25%/50%/100% full valid；第二阶段还比较起点。最终test只评选中状态一次。`selection.json`的epoch为Trainer已完成epoch计数，阶段内位置需结合step（本次选中均为421，即完整epoch）。

四模型整体初始state hash、数据顺序一致，但激活字段/目标不同且相乘模型多预热epoch，属于结构筛查。`content`仅激活B3/B4，其余输入保留但置零；`budget`走固定背景预算；`fusion`与相乘内容塔使用全字段。

原生分域日志的domain0..4是编码值，可用Schema词表还原；最终metrics.json的domains使用原始tab。User-GAUC用raw用户ID、样本加权并排除单类组。报告中的无训练负时钟只作排序诊断，不用于重选checkpoint。

## 文件层

`events.parquet`保存完整日志与排序/切场元数据；`sessions.parquet`保存全部场；`request_events.parquet`保留屏与事件归属（chunk0的request_id为空）；`requests_base.parquet`保存未编码结构；`features_raw.parquet`保留未log/编码的特征与先验支持数；`train/valid/test.parquet`为可训练数据。训练parquet做seed2026物理shuffle，valid/test保持稳定顺序。

`manifest.json`记录协议、split规模、OOV用户、历史覆盖与截断比例；`data_audit.json`记录日期、场景和边界核对。实现/单batch测试在`workspace/kr_time_budget/tests/test_v3.py`，不进入src。
