# 第12份计划：混合威布尔与平均每屏停留特征

已阅读`Argon-plans/11理解.md`、`12下一步.md`，执行第12份的两步实验。主指标保持Pooled AUC、LogLoss，辅助为精确屏号分组Intra-Step GAUC；User-GAUC只作诊断。

## 预先定义的六组配置

| 配置 | 预算分布 | 有效预算时钟 | 平均停留特征 |
| --- | --- | --- | --- |
| single_dual | 原单威布尔 | 分钟×屏数 | 无 |
| mixture_dual | 每时钟K=2混合威布尔 | 分钟×屏数 | 无 |
| mixture_step | K=2混合威布尔 | 仅屏数，分钟gamma固定1 | 无 |
| mixture_step_pace | 同上 | 仅屏数 | 内容侧增加log1p(elapsed_min_raw/req_idx_raw) |
| fusion | 全54字段MLP | 无显式生存公式 | 无额外派生特征 |
| fusion_pace | 同上 | 同上 | 同样增加平均停留特征 |

顺序对照：single_dual→mixture_dual测混合结构；mixture_dual→mixture_step测关闭分钟预算；mixture_step→mixture_step_pace测平均停留特征。Fusion增加相同派生特征，检查显式特征工程是否也改善黑盒。

## 公式与初始化

每时钟预算网输出6维：两组scale/shape、两个混合权重logit。两个时钟共12维。尺度仍为exp(clamp(raw,−2,4.5)+1.6)，shape仍为clamp(0.3+softplus(raw),max=5)。这是第12份要求的capped同口径实验；本轮不同时解除尺度上界，也不把每分量shape强制改成大于1。第11份的短/长潜模式是研究动机，是否学出相应模式由参数和后验诊断判断。

S_mix(t)=Σπ_k·exp(−(t/λ_k)^z_k)。预算存活比为S_mix(t+1)/S_mix(t)。使用logsumexp和随存活更新的后验权重计算，避免两个累计存活都下溢为0时出现0/0；不以固定先验权重平均各分量gamma。

先按原单威布尔模型顺序构建全部共有模块，再替换预算末层，不移动其他参数的随机数序列。每时钟两个分量复制原scale/shape头，scale原始bias分别偏移−log2、+log2，使初始尺度分开；权重logit初始化为0，先验各半。分量形状最初相同，但可独立学习。混合与单分量预算末层大小、初始化和函数不同，比较属于整体分布结构实验，不宣称纯参数量因果收益。

平均停留特征从当前屏结束时已可得的raw分钟和屏号直接计算，网络输入前做log1p。不使用下一屏、剩余场长或未来标签。它描述到当前屏的场内平均分钟，并非严格的上一屏耗时，也不证明因果满意度；原始分钟回退仍保留。模型预算视图34字段不变，内容Omni48字段不变；特定配置在内容向量后显式附加1维，Fusion相应为54+1字段。新第一层列初始化为0，保留原列，保证新特征初始不改变预测（允许浮点矩阵形状导致的1e-7级差异），之后该列可学习。无需重拟合schema或改写数据。

## 固定训练与评估

KR 1K data/v3，train为20220408–20220506、1,721,745条/1000用户；valid为20220507、57,872条/894用户；test为20220508、48,898条/855用户。固定54原字段及原物理顺序，train已shuffle，valid/test不shuffle；只在读取时增加原始分钟别名。

seed2026、2027、2028，每seed六组，共18组；各完整train 1epoch、421步，batch4096，无累积。AdamW预算lr=.005、内容/Fusion lr=.001；普通矩阵衰减1e-6，Embedding/bias/一维参数零衰减，无scheduler/EMA，CPU4线程。所有配置仍只使用最终乘积BCE，一次backward/update同时更新两塔；无辅助Loss、预热、冻结。

完整valid在step0/106/211/421按LogLoss选模型，再对完整test评估。每个checkpoint独立重载核对全部预测；single_dual/Fusion逐seed复现第10份结果。记录首步两塔及独立用户Embedding的梯度和更新，混合先验/后验、lambda/shape、分量退化、时钟回退与累计S单调性。

报告三seed均值/样本标准差、逐seed配对差值、固定屏号桶的真实继续率与平均预测；单独记录第2–10屏的偏差、AUC和LogLoss。不能仅凭桶平均偏差下降就声称曲率已被正确识别；提高性能与潜模式解释分别审阅。
