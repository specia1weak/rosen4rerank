# 架构改动记录

这个目录记录“项目架构优化 / 代码设计”需求下产生的架构级改动。

`AGENTS.md` 负责识别需求；`docs/rosen/request_execution/01_architecture_or_code_design.md` 负责说明这类需求怎么处理；本目录负责留下每次实际架构改动的记录。

## 命名规则

除本 README 外，每个改动记录文件使用：

```text
YYYYMMDD_小标题.md
```

示例：

```text
20260717_target-sort-shuffle.md
20260717_schema-manager-cleanup.md
```

小标题建议短、可搜索、能说明主题。优先使用英文 slug，避免不同系统处理文件名时出现编码问题。

## 建议内容

```markdown
# YYYYMMDD 小标题

## 背景

为什么要改。

## 问题定位

冗余、重复、依赖错乱、抽象错误、行为不透明，或其他。

## 设计决策

采用了什么方案，为什么放在这一层。

## 影响范围

可能影响哪些模块、脚本、数据、实验或历史结果。

## 测试情况

做了哪些验证，结果如何。

## 后续事项

还需要迁移、清理、观察或补实验的内容。
```
