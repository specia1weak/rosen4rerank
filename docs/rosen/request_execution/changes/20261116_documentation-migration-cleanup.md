# 文档迁移残留清理

## 背景与问题定位

独立包已使用 `rosen` 命名空间，但 agent 入口及需求执行规范仍混用旧包名、旧源码路径和旧文档路径。入口还默认引用原实验项目的目录与机器路径，并强制指定任务托管工具。

## 修改

- 当前框架名称、模块引用和路径统一为 `rosen`、`src/rosen/`、`docs/rosen/`。
- 修正需求执行规范路径、`AGENTS.md` 文件名和 schema 文档引用。
- 删除对特定任务托管工具的要求及命令模板，保留进度、日志和训练恢复语义的说明。
- 明确本包与调用方实验项目的边界，取消旧项目笔记目录及机器数据源绝对路径的默认假设。
- 迁移背景和历史记录保留原项目名称，以说明来源。

## 影响范围与验证

仅修改文档，不改变模型、训练、数据处理或公共 API。
通过关键词扫描及入口、执行规范中本仓库文件路径的存在性检查验证；未运行训练或模型测试。
