# 研究记录

`research/` 保存人类可读的研究方案、交接和实验结论，按需要创建以下子目录：

| 目录 | 内容 |
| --- | --- |
| `plans/` | 研究问题、机制假设、实验设计和实施计划 |
| `handoffs/` | 当前进度、产物路径、未解决问题和下一步 |
| `findings/` | 实验结果、对照分析、失败原因和可复用经验 |

记录属于开展研究的项目；使用外部实验项目时，写到该项目的 `research/`。已有历史记录按实际位置查找，未迁移的文件不假定存在于新目录。

目录和文件名使用小写英文，多词用连字符。建议文件名为 `YYYYMMDD_topic.md`；同一课题记录较多时，可在对应类别下创建课题子目录。正文可使用中文。

实验结论应注明数据集、切分、训练与评估口径、关键指标和证据路径。原始日志、checkpoint 和数据留在 `workspace/` 或 `logs/`，文档中引用其路径。

框架 API 和设计说明放在 `docs/rosen/`；框架架构改动记录放在 `docs/rosen/request_execution/changes/`。
